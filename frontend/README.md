# Frontend tuần 1–2

Chạy `npm ci` rồi `npm run dev` trong thư mục `frontend` để xem khung React, Vite và Tailwind CSS. Dùng `npm run build` để kiểm tra bản build. Form ở chế độ xem trước và không nhận thông tin tài khoản.

- [Tuần 1](../tuan1.md) — Khởi tạo khung frontend. Khi tích hợp PDF.js, dùng cùng viewport để render canvas và căn lớp overlay. Giữ tọa độ vùng theo hợp đồng CORE-02. Trước khi triển khai, kiểm tra phép đổi tọa độ trên trang xoay, vùng crop và thực thể nhiều dòng.
- [Tuần 2](../tuan2.md) — Dựng layout và form đăng nhập. Khi chốt CORE-03, FE cần mã lỗi ổn định, trạng thái tác vụ theo từng trang và điều kiện xuất kết quả rõ ràng. FE-01 sẽ kết nối xác thực khi BE-01 và BE-02 sẵn sàng.
